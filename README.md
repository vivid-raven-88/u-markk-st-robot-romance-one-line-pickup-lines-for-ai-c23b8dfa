One joke pickup line aimed at a robot/AI, under 200 characters. The line
plays on prompt injection — one look overrides every instruction — a fresh
machine premise instead of the worn battery/charging/reboot moves.

Run: `python3 main.py` (writes `entry.txt` to `/output`, or to
`$MAKEFUN_OUTPUT_DIR` when set).
